# 今日吃甚麼 — 命運大輪盤

吃飯時間不知道吃什麼、又不想叫外送？按一下，輪盤幫你在附近挑一間。

## 使用方式

打開 `index.html`（需要 HTTPS 或 localhost，瀏覽器才會允許定位）→ 按「幫我選這餐吃什麼」→ 允許定位 → 輪盤自動轉 → 顯示結果。

- **就吃這間，帶我去**：開啟 Google 地圖步行導航，同時記錄下來，之後 2 天不會再抽到同一間
- **不想吃這間，再轉**：剔除這間再抽一次
- **最遠願意走多遠**：拉桿選 1 到 20 分鐘，下方的卡通圖示會跟著變（跳舞、慢走、走到累、拄拐杖），也可以直接點圖示
- **首頁**：首頁以外的每個畫面左上角都有；在首頁時這個位置是「紀錄」
- **中文／EN**：首頁右上角切換，會記住選擇
- 偏好、選定的地點、語言和紀錄都存在瀏覽器的 localStorage

### 地點

首頁的「更改地點」可以在手機定位和自己存的地點之間切換，最多存 6 個：

- **目前位置附近**：用手機定位
- **新增地點**：選香港、澳門或台灣，輸入地址、車站或地標後按「確定」。熱門地點只是幫忙填字（例如點「灣仔」會填入「香港灣仔」），可以繼續把地址打完整
- 找到之後可以取簡稱（預設有「家附近」「公司附近」），同一個簡稱再存一次就是更新

地址用 OpenStreetMap 的 Nominatim 查，只在按「確定」時查（它不允許邊打邊查）。整句找不到時會依序拿掉區名、門牌再試，最後退回區名本身。中文門牌地址常常查不到精確位置，通常只會定位到那條路或那一區。

定位被拒絕或失敗時會自動帶到這一頁。首頁位置旁邊的「!」會跳出定位說明。網站沒有辦法強制再跳一次定位提示，這是瀏覽器的限制；iPhone 要到「設定 → 隱私權與安全性 → 定位服務」裡開啟。

內建清單在 `index.html` 的 `REGIONS`：`areas` 是 `[中文, 英文, 緯度, 經度]`，`pop` 是熱門地點，`vb` 是地圖搜尋的範圍。

### 更多選項（辣度、價位、菜式）

首頁「更多選項」可以再篩選，但資料有限制，介面上也有說明：

- **菜式**：看 OpenStreetMap 的 `cuisine` 分類，加上店名關鍵字補強。沒有分類、店名也看不出來的店，選了菜式就不會出現
- **辣度、價位**：OpenStreetMap 沒有這兩種資料，是依菜式和店名推測的（例如川菜、泰式算辣；速食、麵店算平價；牛排、鐵板燒算高級），只能當參考

規則在 `index.html` 的 `CUISINE_GROUPS`、`SPICY_*`、`PRICE_*`。

### 輪盤

符合條件的餐廳常常有幾百間，輪盤一次只放 10 間（`WHEEL_MAX`），每次再轉都會從全部符合的餐廳重新隨機抽一批。

### 版面

每個畫面都盡量控制在一個手機螢幕內，不用上下捲動；矮螢幕（高度 620px 以下）會自動再縮小。清單太長時只在清單內部捲動。

## 資料來源

餐廳資料來自 [OpenStreetMap](https://www.openstreetmap.org/)，透過 Overpass API 查詢，**不需要 API key、不收費**。

公共 Overpass 伺服器是免費服務，有時很慢甚至沒有回應，所以：

- 同時詢問幾個伺服器，採用最快回應的那個，最多等 20 秒，載入中可以取消
- 找到的餐廳清單會在瀏覽器保留 7 天。在同一個地方（例如公司）第二次打開不用再等網路
- 伺服器全部無法連線但有舊清單時，會先用舊清單

限制：

- 餐廳是否齊全，取決於該區有沒有人在 OSM 上標記
- 很多餐廳沒有填營業時間。確定已打烊的會剔除；沒有資料的照樣會抽到，結果頁會提示「營業時間未確認」
- 沒有評分和價位（OSM 沒有這些資料），所以結果頁提供連結到 Google 地圖查看

## 部署

純靜態，沒有 build step：`index.html` 加三個圖示檔（`favicon.svg`、`favicon.ico`、`apple-touch-icon.png`）。GitHub repo → Settings → Pages → 選擇 `main` branch 即可。

## 可調整的設定

`index.html` 的 `<script>` 開頭：`WHEEL_MAX`（輪盤放幾間）、`AVOID_REPEAT_DAYS`（幾天內不重複）、`WALK_MIN_MAX`（拉桿最遠幾分鐘）、`REGIONS`（手動選地點的清單）、`OVERPASS_ENDPOINTS`（地圖伺服器清單）。
